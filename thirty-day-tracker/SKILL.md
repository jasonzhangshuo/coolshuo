# 30天习惯养成追踪系统

帮助用户通过XP经验值系统追踪30天习惯养成进度，包含每日锚点、微挑战、进度可视化。

## 核心机制

### XP经验值规则

| 任务 | XP |
|------|-----|
| 锚点1：晨间定课 | 10 |
| 锚点2：身体运动 | 10 |
| 锚点3：睡前回顾 | 10 |
| 半山内容发布 | 20 |
| 法义90分钟 | 20 |
| 额外对治1条罪 | 10 |
| **每日满分** | **80** |
| **30天满分** | **2400** |

### 等级系统

| 等级 | XP范围 |
|------|--------|
| 新手 | 0-599 |
| 学徒 | 600-1199 |
| 熟练者 | 1200-1799 |
| 大师 | 1800-2400 |

### 七宗罪对治清单

1. **罪一：研究癖** - 口诀：想研究→先行动
2. **罪二：完美主义** - 口诀：完成比完美更重要
3. **罪三：短视频成瘾** - 口诀：想刷→做1分钟替代行为
4. **罪四：糖瘾** - 口诀：想吃糖→喝水/吃坚果
5. **罪五：熬夜** - 口诀：22:00警报→立即准备睡觉
6. **罪六：草稿箱懦夫** - 口诀：想"再完善"→立即发布
7. **罪七：拖延** - 口诀：2分钟能做→立即做

## 生成进度可视化

### 进度条格式

```
进度：██████████░░░░░░░░░░░░░░░░░░░░ {百分比}%
Day {N}/30 | XP: {累计}/{2400} | 等级：{等级}

📊 统计：
• 三锚点连续完成：{N}天
• 半山内容发布：{N}/30篇
• 七宗罪改善：{N}/7条
```

### 追踪表格式

生成 Markdown 表格追踪每日完成情况：

```markdown
| 日期 | 锚1 | 锚2 | 锚3 | 半山 | 法义 | 对治罪 | XP |
|------|-----|-----|-----|------|------|--------|-----|
| 1.21 | ✅ | ✅ | ✅ | ✅ | ✅ | 罪6 | 80 |
| 1.22 | ✅ | ✅ | ☐ | ✅ | ✅ | 罪2 | 60 |
```
