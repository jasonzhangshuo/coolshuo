# 30天微挑战清单

每天完成1个微挑战，增加参与感和趣味性。

## 第1周：建立习惯（Day 1-7）

| Day | 微挑战 |
|-----|--------|
| 1 | 拍一张你的"戒糖环境"照片（清理前后对比） |
| 2 | 记录今天短视频时间，如果<30分钟奖励自己一个健康零食 |
| 3 | 用1句话总结今天半山内容的核心观点 |
| 4 | 找1个今天法义学习中最触动你的句子，抄写下来 |
| 5 | 今天睡前回顾时，写下"今天最自豪的1件小事" |
| 6 | 长距离跑步时，拍一张路上的风景 |
| 7 | 周复盘：给自己写一封鼓励信（3句话） |

## 第2周：深化觉察（Day 8-14）

| Day | 微挑战 |
|-----|--------|
| 8 | 抓到自己1次"想研究而不是行动"的时刻，记录下来 |
| 9 | 正念慢食时，描述食物的3种感受（味道、质地、温度） |
| 10 | 今天犯了哪条罪？用1句话写下如何对治 |
| 11 | 找出今天法义中1个可以立即应用的点，当天实践 |
| 12 | 记录1次成功抵抗短视频诱惑的时刻 |
| 13 | 今天运动时，专注感受身体的3个部位 |
| 14 | 周复盘：对比第1周，写下1个明显的进步 |

## 第3周：突破挑战（Day 15-21）

| Day | 微挑战 |
|-----|--------|
| 15 | 法义学习后，向老婆分享1个你的收获 |
| 16 | 今天半山内容，用语音输入完成（突破写作舒适区） |
| 17 | 主动找1个佛友/同修分享你的30天挑战进展 |
| 18 | 今天尝试1种新的运动方式或路线 |
| 19 | 写下"如果我坚持完30天，我会..."的3个期待 |
| 20 | 记录今天1次"完成比完美更重要"的实践 |
| 21 | 周复盘：写下目前最大的障碍和应对策略 |

## 第4周：巩固成果（Day 22-30）

| Day | 微挑战 |
|-----|--------|
| 22 | 给30天后的自己写一句话 |
| 23 | 今天法义学习时，做1张思维导图或手写笔记 |
| 24 | 记录今天的能量状态（1-10分），分析原因 |
| 25 | 找出这25天中最有效的1个习惯，加强它 |
| 26 | 今天半山内容，写一篇关于"这30天我学到的"预览 |
| 27 | 提前规划第31天开始的延续计划 |
| 28 | 回顾前27天的追踪表，写下3个最大的变化 |
| 29 | 给帮助过你的人（老婆/佛友）发一条感谢消息 |
| 30 | 完成30天总复盘，拍一张追踪表的照片庆祝 |
